# CampusResolve

A static web application for the Code Fuzion 2026 M1 Hinglish Complaint Router challenge.

##features
- Six department classes: Plumbing, Electrical, Wi-Fi, Mess, Academic, Other.
- Dedicated deterministic classifier with weighted phrase/keyword evidence.
- English and common Romanised Hindi/Punjabi phrase coverage.
- Block, floor, room and urgency extraction.
- Conservative confidence threshold; uncertain cases go to human review.
- Local ticket queue, dashboard, filters, CSV export and human correction.
- Browser-local persistence, latency measurement and local processing cost estimate.

## things we could'nt work on
This is a transparent rules-based classifier, not a trained multilingual model ,Punjabi varies widely by speaker and region; unseen spellings and ambiguous complaints can be misclassified, Data is stored in the current browser only, authentication is not done yet, multi-user synchronization, or real staff notifications.
